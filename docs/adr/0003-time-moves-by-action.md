# Time moves by action, not a real-time clock

In-game time advances only when the player does something: activities cost hours (an 8h shift, a 1h danfo trip, a 15 min chat), walking is free, and sleeping ends the day. A real-time clock would make runs depend on how fast someone walks or reads, which breaks deterministic replay and punishes exploring. The sky and NPC schedules still follow the in-game clock, so the World shows day and night.
